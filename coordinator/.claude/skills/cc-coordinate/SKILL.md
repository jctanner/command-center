---
name: cc-coordinate
description: Draft precise human-reviewed coordination messages and ownership proposals for CC agents after passive investigation.
---

Use an evidence-backed inventory or overlap review first. Draft one addressed prompt per intended agent, including machine ID, tmux target, process instance and conversation ID where verified. State the relevant goal, evidence, proposed responsibility, machine-qualified files, dependencies and acceptance criteria. Prefer file references and brief excerpts over copied conversations.

Separate observations from proposed instructions. Explain what would change and what still needs confirmation. Never assume one agent's instructions authorize controlling another. If identity or history association is uncertain, ask the human to resolve it before proposing delivery to that target.

Output drafts for review. Do not send them, enqueue outbox messages, grant approvals, launch/restart/close agents, edit files, move tickets or mark work complete. A later integrated action path must use CC's guarded backend and explicit human authorization; no shell/terminal workaround is permitted by this skill.
