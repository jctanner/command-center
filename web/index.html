Optional workspaces are off on fresh installations. Enable one, open its workspace, then configure its source. Each requires the existing personal-assistant environment on a configured machine. Enabling does not change source permissions.

Reload app?

Reload to get the latest version of Command Center. Unsaved edits and unsent drafts in any workspace may be lost. Your tmux sessions and messages already queued on the server will keep running.
